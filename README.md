 # 🧬 Sequence Alignment Tool

A bioinformatics web application for DNA sequence alignment using the Needleman-Wunsch (Global Alignment) and Smith-Waterman (Local Alignment) algorithms.

---

## 📌 Project Overview

This project allows users to compare two DNA sequences using classical sequence alignment algorithms.

The application is developed in Python and provides a Streamlit web interface for uploading FASTA files, performing sequence alignment, and downloading the results.

---

## ✨ Features

- Upload FASTA files
- Needleman-Wunsch Global Alignment
- Smith-Waterman Local Alignment
- Alignment Score
- Matches
- Mismatches
- Gaps
- Identity Percentage
- Download Alignment Result

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Install Streamlit

```bash
pip install streamlit
```

### 3. Run the application

```bash
streamlit run app.py
```
